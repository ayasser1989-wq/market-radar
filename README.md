# رادار الأسواق

بوت يمسح 50 سهمًا (25 أمريكيًا و25 سعوديًا) كل 15 دقيقة أثناء جلسات التداول. يرسل لك تنبيهًا على تيليجرام عند ظهور إشارة، ويحدّث لوحة تفتحها من الجوال.

- **مجاني بالكامل:** يعمل على GitHub Actions، والبيانات من Yahoo Finance.
- **تأخير الأسعار:** حوالي 15 دقيقة.
- **لا ينفّذ أي صفقة:** المسح والتنبيه فقط.

## ماذا يراقب

| الإشارة | الشرط |
|---|---|
| حركة قوية | تغيّر اليوم 3% أو أكثر |
| تشبّع بيعي / شرائي | RSI(14) أقل من 30 أو أعلى من 70 |
| تقاطع ذهبي / تقاطع الموت | متوسط 50 يومًا يقطع متوسط 200 يوم |
| اختراق / كسر متوسط 50 | السعر يعبر متوسط 50 يومًا |
| قمة / قاع 52 أسبوعًا | السعر يتجاوز أعلى أو أدنى سعر خلال سنة |
| حجم غير معتاد | حجم اليوم ضعف متوسط 20 يومًا أو أكثر |

- لا يتكرر التنبيه لنفس السهم ونفس الإشارة في اليوم نفسه.
- يصلك التنبيه فقط أثناء جلسة ذلك السوق.

## خطة الصفقة (منطق المتداول)

لكل سهم يحسب البوت درجة من 100، ويعرض خطة شراء كاملة إذا وصلت الدرجة 65 أو أكثر:

| المكوّن | النقاط |
|---|---|
| الاتجاه: فوق متوسط 200، ومتوسط 50 فوق 200، وفوق متوسط 50 | 35 |
| الزخم: MACD إيجابي ويتحسن، وRSI بين 45 و68 | 25 |
| تأكيد حجم التداول | 15 |
| تقلب مناسب (ATR بين 1% و4% من السعر) | 10 |
| جودة النمط | 15 |

**الأنماط:** اختراق قمة 20 يومًا بحجم مرتفع، أو ارتداد من متوسط 50 في اتجاه صاعد، أو استمرار الاتجاه، أو ارتداد من تشبّع بيعي.

**الخطة:**
- الدخول بسعر الإغلاق.
- وقف الخسارة = الدخول − 2×ATR.
- الهدف الأول = 1.5 ضعف المخاطرة، والثاني = 3 أضعاف.
- الكمية تُحسب بحيث لا تتجاوز الخسارة 1% من رأس المال، ولا يتجاوز المركز 20% منه.

**الاختبار التاريخي:** نفس القواعد تُطبَّق على كل يوم في آخر سنتين، وتُحاكى كل صفقة 20 يومًا. إذا لمس السعر الوقف والهدف في نفس اليوم تُحسب خسارة. اللوحة تعرض نسبة النجاح ومتوسط العائد بوحدات R لكل نمط ولكل سهم.

عدّل رأس المال ونسبة المخاطرة في قسم `ACCOUNT` في `watchlist.py`، والحد الأدنى للدرجة في `min_setup_score`.

البوت يعطي خطط شراء فقط، ولا ينفّذ أي صفقة.

## الإعداد (حوالي 15 دقيقة، مرة واحدة)

### 1) أنشئ بوت تيليجرام

1. افتح تيليجرام وابحث عن **@BotFather**، ثم أرسل `/newbot`.
2. اختر اسمًا للبوت. سيعطيك **توكن** يبدأ بأرقام ثم `:`. احفظه.
3. افتح البوت الجديد وأرسل له أي رسالة، مثل "مرحبا".
4. افتح هذا الرابط في المتصفح بعد وضع التوكن مكان `TOKEN`:
   `https://api.telegram.org/botTOKEN/getUpdates`
5. ابحث في الصفحة عن `"chat":{"id":` والرقم الذي بعدها هو **Chat ID**. احفظه.

### 2) ارفع المشروع على GitHub

1. سجّل في [github.com](https://github.com) إن لم يكن لديك حساب.
2. اضغط **New repository** وسمّه `market-radar`. اختر **Public**، لأن الصفحات المجانية تحتاج مستودعًا عامًا، ولا يوجد فيه أي سر.
3. اضغط **uploading an existing file** وارفع كل ملفات هذا المجلد بنفس ترتيبها، بما فيها مجلد `.github`.
   - إن تعذّر رفع مجلد `.github` من الجوال، أنشئ الملف يدويًا: **Add file ← Create new file**، واكتب الاسم `.github/workflows/scan.yml`، ثم الصق محتواه.

### 3) أضف أسرار تيليجرام

ادخل **Settings ← Secrets and variables ← Actions ← New repository secret** وأضف سرّين:

- `TELEGRAM_TOKEN` = التوكن من الخطوة 1
- `TELEGRAM_CHAT_ID` = رقم المحادثة من الخطوة 1

### 4) فعّل الصلاحيات واللوحة

1. ادخل **Settings ← Actions ← General ← Workflow permissions** واختر **Read and write permissions**، ثم احفظ.
2. ادخل **Settings ← Pages**، واختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/docs`، ثم احفظ.
3. ستكون لوحتك على الرابط: `https://اسم-حسابك.github.io/market-radar/`
   - أضفه للشاشة الرئيسية في الجوال ليعمل مثل تطبيق.

### 5) جرّب أول تشغيل

ادخل تبويب **Actions ← رادار الأسواق ← Run workflow**. بعد دقيقة إلى دقيقتين ستتحدّث اللوحة بالأسعار الحقيقية.

## مواعيد العمل

| السوق | الأيام | الوقت (بتوقيت الرياض) |
|---|---|---|
| السعودي | الأحد إلى الخميس | 10:00–15:20 |
| الأمريكي | الاثنين إلى الجمعة | 16:00–00:59 تقريبًا |

- GitHub يؤخّر أحيانًا التشغيل المجدول بضع دقائق، وهذا طبيعي.

## التخصيص

- **تغيير الأسهم:** عدّل `watchlist.py`. الأسهم السعودية تُكتب برقمها متبوعًا بـ `.SR`، مثل `2280.SR` للمراعي.
- **تغيير حساسية التنبيهات:** عدّل قسم `RULES` في نفس الملف. مثلًا، ارفع `big_move_pct` إلى 4 لتقليل التنبيهات.
- **التجربة على جهازك:** `pip install -r requirements.txt` ثم `python scanner.py`.
- **التجربة بلا إنترنت:** `DEMO=1 python scanner.py`، وتعمل ببيانات عشوائية.

## تنبيه

الإشارات أدوات فرز فنية تختصر عليك المراقبة، وليست توصيات. راجع الرسم البياني والأساسيات قبل أي قرار.
